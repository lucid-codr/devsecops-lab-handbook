# Application threat modeling with OWASP Threat Dragon
> Windows · Threat Dragon desktop app · graphical practical

## Create a local model
Install the [Threat Dragon desktop app](https://owasp.org/projects/threat-dragon). Create a model titled Online Shopping Application. Set the owner and reviewer, then add a STRIDE diagram named Online Shopping System.

## Draw the application
- Add User as an external entity, Web Server as a process, and Database as a data store.
- Draw User Requests from User to Web Server and Database Access from Web Server to Database. Mark the application boundary around Web Server and Database.
- Save the diagram and verify that the user request crosses the trust boundary.

## Record STRIDE threats
Create or edit a threat on each named diagram element. Mark the examples Open, add the suggested severity, and enter the mitigation in each threat's mitigation field.
- Spoofing · User · High. Account impersonation. Mitigate with MFA and secure session management.
- Tampering · User Requests · High. Request parameter modification. Validate inputs and enforce server-side authorization.
- Repudiation · Web Server · Medium. Missing audit trail. Record user IDs and timestamps in central transaction logs.
- Information disclosure · Database · High. Customer data exposure. Use encryption and least-privilege database access.
- Denial of service · Web Server · High. Excessive requests. Apply request rate and connection limits.
- Elevation of privilege · Web Server · High. Unauthorized administrative access. Enforce role-based authorization checks.

## Show the professor
Open the diagram, trace the request across the boundary, then open one threat and explain why the proposed mitigation addresses it. Save the model locally as online-shopping-threat-model.json and reopen it to verify that it retains the diagram and six threat records.

## Cleanup and troubleshooting
If a field or menu has moved, look for Add Threat in the selected diagram element's properties. Keep the model JSON for your submission. Remove local practice copies when you no longer need them.
