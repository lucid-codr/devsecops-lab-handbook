# Jenkins declarative and scripted pipelines
> Windows · Jenkins LTS with Pipeline plugin · Python on the Windows agent's PATH

## Prepare a Windows Jenkins agent
If Jenkins is missing, follow [Jenkins setup](03.html#install-and-unlock-jenkins) first. Install Python for all users and put its executable directory on the system PATH. Restart the Jenkins service after changes to PATH. Use the local Windows agent for this practical and ensure the Jenkins service account can read C:\PipelineDemo.
~~~PowerShell
python --version
New-Item -ItemType Directory -Force C:\PipelineDemo
~~~
Copy hello.py from the starter into C:\PipelineDemo.
@file hello.py

## Run a declarative pipeline
In Jenkins, choose New Item → Pipeline, name it PythonPipeline, and select Pipeline script. Leave Groovy Sandbox enabled. Paste the declarative file below and click Save → Build Now. The Build, Test, and Deploy stages print labels for this classroom example. Run Python executes the sample.

## Cleanup and troubleshooting
If python is missing from Console Output, verify Windows and Jenkins use the same system Python installation. If the selected node uses Linux, run the build on the Windows node. Delete the demo job and C:\PipelineDemo when finished.
