# Jenkins installation and freestyle build
> Windows · PowerShell · JDK 21 or a newer JDK supported by your Jenkins LTS

## Install and unlock Jenkins
Install a supported JDK and the [Jenkins LTS MSI](https://www.jenkins.io/doc/book/installing/windows/). Use a dedicated Windows service account and give it read and write access to C:\JenkinsWorkspace. Make javac and java available on the system PATH, then restart the service if you changed it. Use the default port 8080 or update the browser URL throughout this lab.
~~~PowerShell
java -version
javac -version
Get-Service Jenkins
~~~
Open [Jenkins](http://localhost:8080/). If the service is stopped, start it from an administrator PowerShell with Start-Service Jenkins. Read the initial password from the path shown on the unlock screen. Install the suggested plugins, including Pipeline for Lab 4, and create a local admin account.

## Compile in a freestyle job
Create C:\JenkinsWorkspace\HelloWorld and put the starter's HelloWorld.java there. Select New Item → Freestyle project, name it HelloWorld, and add an Execute Windows batch command build step. Paste this into the job configuration, then save and click Build Now.
@file HelloWorld.java
~~~Jenkins Windows batch
cd /d C:\JenkinsWorkspace\HelloWorld || exit /b 1
javac HelloWorld.java || exit /b 1
java HelloWorld
~~~

## Copy and run the build artifact
Replace the batch step with this version and manually trigger a second build.
~~~Jenkins Windows batch
cd /d C:\JenkinsWorkspace\HelloWorld || exit /b 1
javac HelloWorld.java || exit /b 1
if not exist deployment mkdir deployment
copy /Y HelloWorld.class deployment\ || exit /b 1
java -cp deployment HelloWorld
~~~

## Show the professor
Open the latest build's Console Output. Point out the javac command, the linked deployment step, the Hello World from Jenkins line, and Finished: SUCCESS.

## Cleanup and troubleshooting
If java works in PowerShell but fails inside Jenkins, check the service account's effective PATH and folder permissions. Keep Jenkins running for Lab 4, or stop it as Administrator with Stop-Service Jenkins. Remove the demo job and its lab directory when you no longer need the evidence.
