# Custom Docker image and Docker Hub
> PowerShell · Docker Desktop · Docker Hub account with push access

## Build an image with your namespace
Create a repository called dockerlab in Docker Hub using your preferred visibility. Open PowerShell in lab-06. Replace YOUR_DOCKER_ID. Keep the same shell open for the subsequent commands.
~~~PowerShell
$dockerId = "YOUR_DOCKER_ID"
$image = "${dockerId}/dockerlab:v1"
docker build -t $image .
docker image ls "${dockerId}/dockerlab"
~~~
@file index.html
@file Dockerfile

## Run the image
~~~PowerShell
docker run -d --name exp06-web -p 127.0.0.1:8082:80 $image
docker ps --filter name=exp06-web
curl.exe http://localhost:8082
~~~

## Sign in and publish the tag
Use the interactive sign-in or enter a Docker Hub personal access token at the password prompt for docker login -u.
~~~PowerShell
docker login -u $dockerId
docker push $image
~~~

## Show the professor
Open [the custom page](http://localhost:8082/) and point out how the Dockerfile copies it into the Nginx image. Open your Docker Hub repository and show the v1 tag.

## Cleanup and troubleshooting
If a push is denied, verify the account, repository namespace, and token permissions. docker logout clears your Docker Hub sign-in on this machine, so use that step only if you signed in for the lab.
~~~PowerShell
docker rm -f exp06-web
docker image rm $image
~~~
