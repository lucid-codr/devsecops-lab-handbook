# GitHub collaboration and repository management
> PowerShell · Git for Windows · GitHub account · Optional collaborator

## Publish the starter project
Create an empty GitHub repository called student-project. Open PowerShell in lab-02. The ZIP includes a home page, CSS and JS folders, and a project report. The .example files are templates for the feature step.
@file index.html
@file js/script.js
~~~PowerShell
git init
git config user.name "YOUR_NAME"
git config user.email "YOUR_GIT_EMAIL"
git status
git add .
git commit -m "Add student project"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USER/student-project.git
git push -u origin main
~~~

## Submit a pull request
Create a feature branch, copy the two templates, and add a link to login.html from index.html if desired.
@file login.html.example
@file css/login.css.example
~~~PowerShell
git switch -c feature-login
Copy-Item login.html.example login.html
Copy-Item css/login.css.example css/login.css
git add .
git commit -m "Add login page"
git push -u origin feature-login
~~~
On GitHub, open a pull request with base main and compare feature-login. Review Files changed with a collaborator if available. Merge the pull request, then synchronize locally. Leave the feature branch on GitHub until cleanup.
~~~PowerShell
git switch main
git pull --ff-only origin main
git branch -a
~~~

## Resolve a local conflict
Use a new branch after updating main. The merge should stop at README.md. Open the file, remove the conflict markers, and combine the two changes before staging.
~~~PowerShell
git switch -c practice-conflict
Set-Content README.md "Version B"
git commit -am "Edit README on practice branch"
git switch main
Set-Content README.md "Version A"
git commit -am "Edit README on main"
git merge practice-conflict
~~~
~~~PowerShell
git diff
git add README.md
git commit -m "Resolve README conflict"
git push origin main
git log --graph --oneline --all
~~~

## Inspect remotes and clone
~~~PowerShell
git remote -v
git remote rename origin github
git remote rename github origin
Set-Location ..
git clone https://github.com/YOUR_GITHUB_USER/student-project.git student-project-check
Set-Location student-project-check
git status
git log --oneline -5
~~~

## Show the professor
Open the merged pull request and its Files changed tab. Show the resolved README and the two merge parents in the Git history.

## Cleanup and troubleshooting
If you need to restart conflict resolution before committing, run git merge --abort. To tidy the remote, delete feature-login from the merged PR or run git push origin --delete feature-login from your original clone if the branch still exists. Keep the repository while you need the PR evidence.
