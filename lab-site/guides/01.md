# Git commands
> PowerShell · Git for Windows · GitHub account

## Create and publish a repository
Install [Git for Windows](https://git-scm.com/download/win). On GitHub, create an empty repository named git-lab. Extract the starter, then open PowerShell in lab-01. Configure your identity for this repository.
~~~PowerShell
git --version
git init
git config user.name "YOUR_NAME"
git config user.email "YOUR_GIT_EMAIL"
git status
git add index.html
git commit -m "Add home page"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USER/git-lab.git
git remote -v
git push -u origin main
~~~

## Clone, branch, and merge
Clone alongside the starter directory. Configure your identity in the clone as well. Open index.html, change the heading, and save before staging.
~~~PowerShell
Set-Location ..
git clone https://github.com/YOUR_GITHUB_USER/git-lab.git git-lab-clone
Set-Location git-lab-clone
git config user.name "YOUR_NAME"
git config user.email "YOUR_GIT_EMAIL"
git switch -c feature
~~~
~~~PowerShell
git diff
git add index.html
git commit -m "Update home page heading"
git push -u origin feature
git switch main
git merge feature
git push origin main
git pull origin main
git fetch origin
git branch -a
~~~

## Inspect history, stash, and tag
Edit index.html again before running the stash example. Restore that edit after inspecting it. The rebase should report that feature is up to date after the earlier merge.
~~~PowerShell
git diff
git stash push -m "Temporary home page edit"
git stash list
git stash pop
git restore index.html
git switch feature
git rebase main
git switch main
git tag v1.0
git push origin v1.0
git log --graph --oneline --all
git show
~~~

## Practice undo and remote management
Run these in the disposable clone with a clean working tree. The hard reset discards local changes. The soft reset removes the empty practice commit while preserving the index and working tree.
~~~PowerShell
git status
git commit --allow-empty -m "Practice reset"
git reset --soft HEAD~1
git rm index.html
git restore --staged --worktree index.html
git mv index.html home.html
git status
git mv home.html index.html
git reset --hard HEAD
git branch -d feature
git remote remove origin
git remote add origin https://github.com/YOUR_GITHUB_USER/git-lab.git
git fetch origin
git status
~~~

## Show the professor

## Cleanup and troubleshooting
If the first push is rejected, check that the GitHub repository was created empty and that the remote points to your repository. Keep the remote for evidence or delete your disposable repository and local clone when finished.
