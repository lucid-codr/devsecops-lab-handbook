# Docker containers and resource management
> PowerShell · Docker Desktop running Linux containers

## Build and run a Python image
Open PowerShell in lab-05 and confirm Docker can reach its engine. The final command should print Hello from Docker!
~~~PowerShell
docker version
docker compose version
docker run --rm hello-world
docker build -t exp05-python .
docker run --rm exp05-python
~~~
@file hello.py
@file Dockerfile

## Explore interactive containers
Enter each container individually. Try cat /etc/os-release, then exit before launching the next one. In Python, try print("Hello from Python"), then exit().
~~~PowerShell
docker run --rm -it alpine sh
docker run --rm -it ubuntu bash
docker run --rm -it python:3.12
~~~

## Start Nginx and MySQL
Start Nginx, then open [the welcome page](http://localhost:8081/). For MySQL use a disposable lab password. Wait for docker logs to report that MySQL is ready, then enter the same password at the prompt.
~~~PowerShell
docker run -d -p 127.0.0.1:8081:80 --name exp05-nginx nginx
curl.exe http://localhost:8081
~~~
~~~PowerShell
$mysqlPassword = Read-Host "Disposable MySQL password"
docker run -d --name exp05-mysql -e "MYSQL_ROOT_PASSWORD=$mysqlPassword" mysql:8.0
Remove-Variable mysqlPassword
docker logs exp05-mysql
~~~
~~~PowerShell
docker exec -it exp05-mysql mysql -uroot -p
~~~
~~~MySQL console
SHOW DATABASES;
EXIT;
~~~

## Manage a container, image, network, and volume
List images and containers. Stop and restart Nginx. Connect it to a lab network, then disconnect it. The two Alpine containers below share a volume, so the second one can read the file after the first exits.
~~~PowerShell
docker images
docker ps -a
docker stop exp05-nginx
docker start exp05-nginx
docker network create exp05-network
docker network connect exp05-network exp05-nginx
docker network inspect exp05-network
docker network disconnect exp05-network exp05-nginx
docker volume create exp05-volume
docker volume inspect exp05-volume
docker run --rm -v exp05-volume:/data alpine sh -c "echo 'Lab data' > /data/student.txt"
docker run --rm -v exp05-volume:/data alpine cat /data/student.txt
~~~

## Show the professor
Show the Nginx page, the running containers in docker ps, and the persisted student.txt from a fresh container. Explain how a running container differs from its image and its named volume.

## Cleanup
The following commands remove the lab containers and their data, the named network and volume, and the custom lab image. If 8081 is already occupied, pick another free host port.
~~~PowerShell
docker rm -fv exp05-nginx exp05-mysql
docker network rm exp05-network
docker volume rm exp05-volume
docker image rm exp05-python
~~~
