# SAST and code quality analysis with SonarQube
> Windows · PowerShell · Docker Desktop · Node.js LTS

## Start SonarQube locally
~~~PowerShell
docker run -d --name exp10-sonar -p 127.0.0.1:9000:9000 sonarqube:community
docker logs -f exp10-sonar
~~~
Wait for SonarQube to become operational, then press Ctrl+C to stop following logs. Open [SonarQube](http://localhost:9000/) and update the initial password when prompted. Create a local project with key sonar-exp10. Choose local analysis and generate a project token. Keep that token private.

## Review the source and scan
Open PowerShell in lab-10. The scanner reads the project key, source folder, and server URL from sonar-project.properties. Enter your token at the masked prompt. The environment variable is removed after the scan.
@file app.js
@file sonar-project.properties
~~~PowerShell
$secret = Read-Host "SonarQube project token" -AsSecureString
$env:SONAR_TOKEN = [System.Net.NetworkCredential]::new("", $secret).Password
try {
    npx.cmd --yes @sonar/scan
} finally {
    Remove-Item Env:SONAR_TOKEN
    Remove-Variable secret
}
~~~

## Review the dashboard and rescan
Open [the project dashboard](http://localhost:9000/dashboard?id=sonar-exp10) after the analysis task completes. Find the quality gate and review the Issues tab, including maintainability findings about var if your quality profile enables that rule. Replace the two var declarations with const and rerun the analysis to compare results. [SonarScanner for NPM](https://docs.sonarsource.com/sonarqube-server/analyzing-source-code/scanners/npm/using)

## Show the professor
Show the quality gate, one issue with its source location and rule rationale, and the result after remediation. Actual issue counts depend on the installed version and quality profile.

## Cleanup and troubleshooting
If SonarQube exits during startup, inspect docker logs exp10-sonar for the failed bootstrap check and consult the [SonarQube installation requirements](https://docs.sonarsource.com/sonarqube-server/server-installation/pre-installation/linux). Keep the container while you need the dashboard. Revoke the project token after the demo. To remove the container and its lab data, run the following.
~~~PowerShell
docker rm -fv exp10-sonar
~~~
