# Prometheus monitoring and Alertmanager
> Ubuntu on WSL2 · Docker Desktop with Ubuntu integration

## Review the monitoring configuration
Extract lab-08 under your WSL home directory. Prometheus scrapes itself and Node Exporter every 15 seconds. NodeExporterDown fires after the node target has stayed down for 30 seconds. Alertmanager displays the alert with the default receiver.
@file prometheus.yml
@file alert_rules.yml
@file alertmanager.yml

## Start the three lab services
Run from lab-08 in WSL. The published endpoints are loopback-only. Docker's internal monitoring network gives Prometheus access to each container by name.
~~~WSL Bash
docker network create exp08-monitoring
docker run -d --name node-exporter --network exp08-monitoring -p 127.0.0.1:9100:9100 prom/node-exporter
docker run -d --name alertmanager --network exp08-monitoring -p 127.0.0.1:9093:9093 -v "$PWD/alertmanager.yml:/etc/alertmanager/alertmanager.yml:ro" prom/alertmanager
docker run -d --name prometheus --network exp08-monitoring -p 127.0.0.1:9090:9090 -v "$PWD/prometheus.yml:/etc/prometheus/prometheus.yml:ro" -v "$PWD/alert_rules.yml:/etc/prometheus/alert_rules.yml:ro" prom/prometheus
docker ps --filter network=exp08-monitoring
~~~
Open [Prometheus targets](http://localhost:9090/targets) and wait until both are UP. Open [the query page](http://localhost:9090/query) and run up. Both series should be 1.

## Trigger and resolve the alert
Stop the lab exporter and watch the [Prometheus alerts screen](http://localhost:9090/alerts) until NodeExporterDown is firing. Check [Alertmanager](http://localhost:9093/#/alerts) after the grouping delay.
~~~WSL Bash
docker stop node-exporter
~~~
Start the exporter again. After the next evaluation, verify that the target returns to UP and that the alert clears.
~~~WSL Bash
docker start node-exporter
~~~

## Show the professor
Show the target, the alert expression, and the change from inactive to firing and back. Allow around a minute for the firing state during a live demo.

## Cleanup and troubleshooting
For missing targets or startup failures, inspect docker logs prometheus and docker logs alertmanager. Check that the YAML files were extracted into the current directory and mounted as files.
~~~WSL Bash
docker rm -fv prometheus alertmanager node-exporter
docker network rm exp08-monitoring
~~~
