# Ansible Nginx installation and web deployment
> Ubuntu on WSL2 · systemd · sudo permission · dedicated lab distro

## Configure the managed node
For a one-machine demo, use the same dedicated Ubuntu WSL distro as both the controller and the SSH-managed node. Keep SSH on loopback so the experiment can run without setting up a second Windows PC or LAN forwarding. Use a dedicated distro because the playbook replaces the default Nginx page.
~~~WSL Bash
sudo apt update
sudo apt install ansible openssh-server
whoami
~~~
Set the SSH server to bind to 127.0.0.1. First check the effective configuration and any existing ListenAddress entries. On a clean Ubuntu distro, add the following line in /etc/ssh/sshd_config.d/00-devsecops-lab.conf. If other active ListenAddress entries exist, remove those in this dedicated distro before continuing.
~~~SSH configuration
ListenAddress 127.0.0.1
~~~
~~~WSL Bash
sudo sshd -t
sudo systemctl stop ssh.socket
sudo systemctl restart ssh
sudo ss -lntp
~~~
If ssh.socket is absent on your Ubuntu release, continue with the ssh service. Verify SSH is listening only on 127.0.0.1 before connecting.

If you have no SSH key, use ssh-keygen -t ed25519. Accept the default path only if that file does not already exist. To authorize your existing or new Ed25519 key for this local lab account, append its public key once.
~~~WSL Bash
install -d -m 700 ~/.ssh
cat ~/.ssh/id_ed25519.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
ssh "$USER@127.0.0.1" whoami
~~~

## Verify Ansible connectivity
Extract lab-07 under your WSL home directory. Replace YOUR_WSL_USER in inventory.ini with the output of whoami. Run the check from that directory. If using a custom SSH key path, load the key into your agent or provide it with --private-key.
@file inventory.ini
~~~WSL Bash
ansible -i inventory.ini webservers -m ping
~~~

## Install Nginx and deploy the page
Run the playbooks one at a time. Enter your WSL sudo password at the BECOME prompt. The recap should show failed=0 and unreachable=0.
@file install-nginx.yml
@file deploy.yml
~~~WSL Bash
ansible-playbook -i inventory.ini install-nginx.yml --ask-become-pass
ansible-playbook -i inventory.ini deploy.yml --ask-become-pass
~~~

## Show the professor
Show the inventory, successful play recap, and deployed HTML.
~~~WSL Bash
ssh "$USER@127.0.0.1" curl -fsS http://127.0.0.1/
~~~

## Cleanup and troubleshooting
If SSH fails, verify it works manually before running Ansible. If Nginx has a bind error, check for a process on port 80 in the WSL distro. Stop the two lab services when done. Keep or remove the lab distro according to whether you need the evidence.
~~~WSL Bash
sudo systemctl stop nginx ssh
~~~
